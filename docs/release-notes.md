# CodeScope v1.0.0

Первый релиз локального проверяльщика Python, C++, C# и Java.

- Редактор, вкладки файлов, переход к проблемной строке, светлая и тёмная темы.
- Ruff / Bandit / Pyright; G++ / Cppcheck; Roslyn / .NET 8; javac.
- Честное покрытие: отсутствующий инструмент обозначается как частичная проверка.
- JSON и автономный HTML-отчёт. Готовые примеры для всех четырёх языков.
- CLI, loopback API, ограничения входных данных и времени.

Скачай `codescope-1.0.0.zip`, распакуй и запусти `run.bat` либо `sh run.sh`.
Нужны Python 3.10+, интернет для установки и Node.js для Pyright. Компиляторы C++/C#/Java устанавливаются отдельно; Dockerfile содержит полный набор.

**Не готовый EXE. Не облачная песочница. Не доказательство правильности кода.** Пользовательские программы не запускаются; Java/C# могут компилироваться во временные артефакты. Подробности и ограничения — в README и SECURITY.md.

Вложены настоящие скриншоты интерфейса, пример HTML-отчёта и SHA-256 ZIP-архива. Статическое демо: https://ggrrrt5543.github.io/ggrrrt5543/codescope/.
